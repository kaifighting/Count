第一部分

先看懂三樣東西的關係

小記帳
像你的記帳本
在手機上記下每天花了多少錢，還會畫圖表給你看。
GitHub
像放設計圖的雲端櫃子
保存小記帳的程式，並免費把它變成一個網址。
Claude Code
像幫你改設計圖的工人
你用講的，它去改程式、測試，再交給你檢查。

每次想讓小記帳多一個功能，都是走同一條路：

  1. 你告訴 Claude Code 想要什麼
  2. 它把程式改好，放在「草稿」
  3. 你同意後，草稿合併成「正式版」
  4. 手機上的小記帳自動更新
你的花費資料不在 GitHub 上。GitHub 放的只有程式。你記的每一筆帳，只存在你自己手機的瀏覽器裡。
第二部分

小記帳怎麼用

打開它，放到手機桌面

  1. 用手機的 Chrome 打開 https://kaifighting.github.io/Count/。
  2. 點 Chrome 右上角的「⋮」，選「加到主畫面」或「安裝應用程式」。
  3. 桌面出現小記帳的圖示，之後點圖示就能打開。

如果網址打不開，請看「GitHub 怎麼用」裡的檢查網站有沒有開。

畫面最上面

  • 今日／本週／本月：選你想看哪一段時間。
  • 大數字：那段時間總共花了多少錢。

四個分頁

分頁用來做什麼
記一筆記下一筆花費。可以按麥克風說「早餐 85」，也可以自己輸入金額、選類別，再按「記下這筆」。
圖表圓餅圖告訴你錢花在哪一類。選「本週」或「本月」會多一張每天花費的長條圖；選「本月」還會有累計的折線圖。
明細每一筆花費的清單。右邊的「✕」是刪除。標「通知」的是刷卡通知記的，標「發票」的是發票匯入的。
匯入讓發票和刷卡紀錄自己進來，不用一筆一筆打。裡面有四張卡片，看下一張表。

「匯入」分頁的四張卡片

卡片做什麼什麼時候用
載具發票匯入選一個發票明細檔，自動變成記帳紀錄。手上有財政部的明細檔時
刷卡通知記帳貼上銀行通知的文字，自動抓出金額和店家。想試試看，或偶爾補一筆
自動讀取發票信財政部寄到 Gmail 的發票信，打開 App 時自動匯入。設定一次，之後全自動
收到推播自動記帳銀行 App 一跳出刷卡通知，就自動記一筆。設定一次，之後全自動

同一張發票不會被記兩次。如果同一天已經有一筆金額相同的刷卡通知，發票進來時會跟它合併成一筆。

資料只在這支手機裡。清除 Chrome 的網站資料、換手機、或把 App 移除，紀錄都會不見。目前還沒有備份功能。
第三部分

設定自動記帳

這兩個設定都只要做一次。請用手機上同一個瀏覽器做完，因為小記帳會在這支手機裡記住一把專屬的鑰匙。

自動讀取發票信（Gmail）

  1. 在小記帳的「匯入」分頁，按「複製程式碼」。
  2. 打開 script.google.com，建立新專案。
  3. 把裡面原本的字全部刪掉，貼上剛才複製的內容，按儲存。
  4. 按右上角「部署」，選「新增部署作業」。
  5. 類型選「網頁應用程式」，執行身分選「我」，誰可以存取選「所有人」。
  6. 按「部署」。Google 會說「這個應用程式未經驗證」，點「進階」再點「前往」，然後允許。
  7. 複製畫面上結尾是 /exec 的網址，貼回小記帳，按「連結並同步」。
為什麼會有警告？因為這段程式是你自己建的，不是商店裡上架的產品。它只會找財政部寄來的信、讀裡面的附件，不會改信也不會刪信。那個 /exec 網址不要給別人。
這個功能還沒在真的 Gmail 上試過。如果小記帳顯示錯誤訊息，把那一行字原封不動貼給 Claude Code，它就能照真實的信件格式調整。

收到推播自動記帳（Android）

  1. 到 Play 商店安裝 MacroDroid，新增一個巨集。
  2. 觸發條件選「收到通知」，App 選你的銀行 App。
  3. 動作選「開啟網站」，網址貼上小記帳卡片裡那一串，並在最後面插入「通知內容」這個變數。
  4. 勾選網址編碼，然後儲存。
先試一則真的通知。每家銀行的通知寫法不一樣。先把一則真實通知貼到「刷卡通知記帳」試試，抓錯了就把那則通知貼給 Claude Code。MacroDroid 的選單名稱可能和這裡寫的不完全一樣。
第四部分

GitHub 怎麼用

先認識七個詞

詞白話
Repository一個專案的資料夾，常簡稱 repo。小記帳的 repo 叫 Count。
Commit一次「存檔」。會記下誰、什麼時候、改了什麼。
Branch草稿本。在草稿上改，不會動到正式版。
main正式版。你的網站用的就是它。
Pull Request簡稱 PR。意思是「請把草稿併進正式版」的申請單。
Merge合併。同意申請，草稿就變成正式版。
GitHub Pages把 repo 裡的檔案變成網站的免費功能。

常做的五件事

先到 github.com/kaifighting/Count 並登入。

  • 看檔案：首頁就是檔案清單，點檔名可以看內容。
  • 看修改歷史：點檔案清單上方的「Commits」。
  • 看 PR：點上方的「Pull requests」。已經合併的在「Closed」裡。
  • 合併 PR：進 PR 頁面，按綠色的「Merge pull request」，再按「Confirm merge」。也可以直接請 Claude Code 合併。
  • 反悔：進已合併的 PR 頁面，按「Revert」。它會產生一個「改回去」的新 PR，合併它就復原了。

檢查網站有沒有開

  1. 進 Count，點上方的「Settings」，再點左邊的「Pages」。
  2. 「Source」要選「Deploy from a branch」，Branch 選 main，資料夾選 / (root)，按 Save。
  3. 設好後，頁面上方會顯示你的網址。
  4. 每次合併後，到上方的「Actions」看。出現綠色勾勾，就代表網站更新好了，通常一兩分鐘。
公開的 repo 安全嗎？免費帳號的 repo 要設成公開才能用 Pages。公開的意思是別人看得到程式，但看不到你的花費。
第五部分

請 Claude Code 幫忙

它能做的

  • 讀小記帳的程式，照你的話修改，並且自己先測試。
  • 把改好的東西放到草稿，你開口時幫你開 PR 或合併。
  • 查資料，解釋你看不懂的東西。

它不會自己做的

  • 你沒開口，它不會開 PR，也不會合併。
  • 它連不到你的手機、Gmail、銀行和你的網站。實際用起來怎麼樣，要你試了告訴它。

這樣講最有效

  • 用白話說想要的結果。例如「我想在明細裡可以改金額」。
  • 一次講一件事。做完一件再講下一件。
  • 出問題時給原本的東西。錯誤訊息原文、截圖、真實的通知文字，卡號可以塗掉。
  • 不懂就問。例如「這個按鈕是做什麼的？」
做好的東西都在 GitHub。每次對話，Claude Code 都是在一台臨時的雲端電腦上工作，對話結束那台電腦就會消失。所以它會把成果放到 GitHub，那裡才是永久保存的地方。
